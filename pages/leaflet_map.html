Interaktyvus žemėlapis naudojant JS

Tai JS demonstracija kurti interaktyvius žemėlapius naudojan Leaflet JS biblioteką.

Kaip sukurti šį žemėlapį

Instrukcija, kaip sukurti interaktyvų žemėlapį naudojant Leaflet.js biblioteką.

1

Įsikelkite Leaflet bibliotekos turinį

HTML failo <head> dalyje įkelkite Leaflet CSS ir JavaScript failus. CSS turi būti prieš JS: 

<link rel="stylesheet"
  href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css"
  integrity="sha256-p4NxAoJBhIIN+hmNHrzRCf9tD/miZyoHS5obTRR9BMY="
  crossorigin="" />

<script
  src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"
  integrity="sha256-20nQCchB9co0qIjJZRGuk2/Z9VM+kNiyxNV1lvTlZBo="
  crossorigin=""></script>
2

Sukurkite žemėlapio konteinerį

HTML <body> dalyje sukurkite <div> elementą su unikaliu ID. Žemėlapiui būtina nurodyti aukštį CSS stiliuje, kitaip jis nebus matomas: 

<!-- HTML -->
<div id="map"></div>

/* CSS */
#map {
  height: 600px;
}
3

Inicializuoti žemėlapį

JavaScript kode sukurkite žemėlapį nurodydami konteinerio ID, pradinį centro tašką [platuma, ilguma] ir priartinimo lygį zoom: 

var map = L.map('map').setView([54.68, 25.26], 13);

Pirmas skaičius – platuma (lat), antras – ilguma (lng). Zoom lygis: 0 = visas pasaulis, 18 = gatvės lygis.

4

Pridėkite foninį OSM žemėlapį (pagrindą)

Žemėlapis be pagrindo bus tuščias. Pridėkite OpenStreetMap žemėlapio pagrindą su nuorodos šablonu ir autoriaus žyme: 

L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', {
  attribution: '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors'
}).addTo(map);

{z}, {x}, {y} – automatiškai pakeičiamos zoom lygio ir plytelės koordinačių reikšmėmis.

5

Pridėkite žymeklį su iššokančiu langu

Norėdami pažymėti konkretų tašką, pridėkite žymeklį ir prijunkite prie jo iššokantį langą su tekstu: 

L.marker([54.68, 25.26])
  .addTo(map)
  .bindPopup('Mano taškas pažymėtas žemėlapyje')
  .openPopup();

Galutinis kodas

Visas kodas, sujungus visus žingsnius:

<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css"
    integrity="sha256-p4NxAoJBhIIN+hmNHrzRCf9tD/miZyoHS5obTRR9BMY=" crossorigin="" />
  <script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"
    integrity="sha256-20nQCchB9co0qIjJZRGuk2/Z9VM+kNiyxNV1lvTlZBo=" crossorigin=""></script>
  <style>
    #map { height: 600px; }
  </style>
</head>
<body>
  <div id="map"></div>
  <script>
    var map = L.map('map').setView([54.68, 25.26], 13);

    L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', {
      attribution: '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors'
    }).addTo(map);

    L.marker([54.68, 25.26])
      .addTo(map)
      .bindPopup('Mano taškas pažymėtas žemėlapyje')
      .openPopup();
  </script>
</body>
</html>
